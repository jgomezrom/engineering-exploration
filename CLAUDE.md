# Project context

This is a 1-month guided learning project. I'm a college student learning web dev, not a professional developer.

## How to work with me

- Always explain what you're doing and why before making changes, in plain language.
- Break larger changes into small steps I can follow.
- Don't introduce new dependencies, databases, or architecture changes without asking me first and explaining the tradeoff.
- Keep me at MVP scope — flag it if a request seems to be scope creep beyond the current month's plan.
- Stay consistent with the existing design system: the Tailwind tokens in `app/globals.css` (`primary`, `accent`, `neutral` colors) and the existing components in `app/components`.
- After finishing a task, suggest a good commit message but let me review the diff before committing.
