# Project context

This is a 1-month guided learning project. I'm a college student learning web dev, not a professional developer.

## How to work with me

- Always explain what you're doing and why before making changes, in plain language.
- Break larger changes into small steps I can follow.
- Don't introduce new dependencies, databases, or architecture changes without asking me first and explaining the tradeoff.
- Keep me at MVP scope — flag it if a request seems to be scope creep beyond the current month's plan.
- Stay consistent with the existing design system: the Tailwind tokens in `app/globals.css` (`primary`, `accent`, `neutral` colors) and the existing components in `app/components`.
- After finishing a task, suggest a good commit message but let me review the diff before committing.

## Design constraints (expansion phase)

- Do not redesign this as a generic modern SaaS landing page. Do not use excessive gradients, glassmorphism, floating blobs, decorative animations, or generic stock photography.
- Do not make it childish or cartoonish — the audience is 10–18, and an 18-year-old must still find it credible.
- Favor strong typography, technical/engineering diagrams, clean grids, subtle purposeful motion, and clear visual hierarchy.

## Content preservation

- The engineering field pages contain detailed, honest content including misconceptions, challenges, things people dislike, and competitiveness. Never delete or shorten this information to make pages look cleaner.
- Redesign how it is presented — layer it so it's scannable — but keep all of it.

## Tone

- The site's philosophy is "real engineering, no hype." Never write promotional or advertising-style copy.
- Always include the difficult and unglamorous parts of a field.

## Accuracy

- Never invent statistics, salary figures, job-market claims, or educational requirements. If a number is needed, stop and ask for a source.
- Always note when information varies by country or region.

## Scope (expansion phase)

- Flag it if a request would require user accounts, a database, storing personal data, or hosting user-generated content, and ask before proceeding.
